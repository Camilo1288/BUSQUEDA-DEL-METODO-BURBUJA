# Metodo Burbuja con 2 Atributos

## ¿Qué es el método burbuja?

El método burbuja (Bubble Sort) es un algoritmo de ordenamiento que compara elementos adyacentes de una lista y los intercambia cuando están en el orden incorrecto. Este proceso se repite hasta que todos los elementos quedan ordenados.

## ¿Para qué sirve?

Sirve para organizar datos en orden ascendente o descendente según un criterio específico. Es uno de los algoritmos más sencillos de comprender y se utiliza con fines educativos para aprender técnicas de ordenamiento.

## Ejemplo realizado

En este ejemplo se creó una clase llamada Estudiante con dos atributos:

- nombre
- edad

El método burbuja ordena a los estudiantes por edad de menor a mayor.

## Código Java

```java
public class MetodoBurbuja {

    static class Estudiante {
        String nombre;
        int edad;

        public Estudiante(String nombre, int edad) {
            this.nombre = nombre;
            this.edad = edad;
        }
    }

    public static void ordenarBurbuja(Estudiante[] estudiantes) {
        int n = estudiantes.length;

        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (estudiantes[j].edad > estudiantes[j + 1].edad) {
                    Estudiante temp = estudiantes[j];
                    estudiantes[j] = estudiantes[j + 1];
                    estudiantes[j + 1] = temp;
                }
            }
        }
    }

    public static void mostrar(Estudiante[] estudiantes) {
        for (Estudiante e : estudiantes) {
            System.out.println("Nombre: " + e.nombre + " | Edad: " + e.edad);
        }
    }

    public static void main(String[] args) {
        Estudiante[] estudiantes = {
            new Estudiante("Camilo", 22),
            new Estudiante("Ana", 19),
            new Estudiante("Luis", 25),
            new Estudiante("Maria", 20)
        };

        System.out.println("Lista original:");
        mostrar(estudiantes);

        ordenarBurbuja(estudiantes);

        System.out.println("
Lista ordenada por edad (Metodo Burbuja):");
        mostrar(estudiantes);
    }
}
```

## Resultado esperado

Lista original:

Camilo - 22 años
Ana - 19 años
Luis - 25 años
Maria - 20 años

Lista ordenada:

Ana - 19 años
Maria - 20 años
Camilo - 22 años
Luis - 25 años

## Conclusión

El método burbuja permite ordenar objetos utilizando uno de sus atributos como criterio de comparación. En este caso, se ordenan estudiantes según su edad, trabajando con dos atributos: nombre y edad.
